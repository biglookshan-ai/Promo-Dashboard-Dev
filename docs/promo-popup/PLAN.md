# 促销弹窗(节日活动小弹窗)· 实现方案

> 2026-11-02 起草。状态:**方案待用户确认**,还没写代码。
> 用户需求:客人打开网站时,自动在底部弹出一个活动小卡片(不是全屏、不挡操作),3–5 秒后自动隐藏,带倒计时;
> 弹过一次至少隔 1 小时才再弹;有些页面不弹(比如黑五活动页本身);电脑、手机都要好看。

## ✅ 已经和用户定好的

| 问题 | 决定 |
| --- | --- |
| 给谁看 | **所有进网站的客人**(不分是否登录会员),频率按浏览器记 |
| 频率 | 弹过一次**至少隔 1 小时**才再弹,**每天最多 3 次**(每个弹窗可改);客人**手动点 × 关掉 → 当天不再弹** |
| 位置 | **电脑:左下角小卡片**;**手机:底部整条** |
| 内容 | **小图 + 标题 + 一句话 + 倒计时 + 按钮**(文字用网站字体,不做成一整张图) |

## 🧭 方案合不合适

合适,而且和现有系统很顺:

- 网站更新中心已经有一整套「内容按时间自动上下线」的机制(Banner、顶栏、产品页推广都在用):
  内容存在 Shopify 的内容类型里,**到点由定时器切成「上线」,结束切回「草稿」**,主题只读得到上线中的。
  弹窗照这个做:**新增一种内容「促销弹窗」**,不需要新的 app、不需要额外的服务器接口。
- **可以跟随活动**:选「跟随 Black Friday」,弹窗的上下线时间和倒计时都自动用活动的时间,活动改时间弹窗跟着变。
- 弹窗在**页面打开时就已经由 Shopify 一起生成**(和 Banner 一样在服务器上读),不会出现「读不到」或闪一下的情况;
  没有上线中的弹窗时,主题里什么都不输出,对网站速度零影响。
- 「哪些页面不弹」**在服务器上就判断好**,被排除的页面连弹窗的代码都不会出现。

需要注意的几点(下面方案里都处理了):
1. 网站底部已经有东西:**左下角 Cookie 提示**(第一次来的客人才有)、**右下角聊天按钮**(Shopify Inbox)、**底部中间「回到顶部」按钮**(往下滚才出现)。
2. 部分产品页模板有**底部固定的加购条**,手机上要避开。
3. 购物车抽屉、搜索弹窗、手机菜单打开时不能弹。

### 动作
| 时刻 | 发生什么 |
| --- | --- |
| 页面加载完 + 等 2 秒(可改 0–10 秒) | 从下往上滑出(手机)/ 淡入上移(电脑) |
| 显示中 | 倒计时每秒走;**鼠标停在卡片上 / 手指按住时暂停计时**,不会在客人正要点的时候消失 |
| 5 秒后(可改 3–10 秒) | 自动滑出隐藏,记一次「显示过」 |
| 点按钮或卡片 | 去活动页(带上统计参数,见下) |
| 点 × | 马上关掉,**这个弹窗当天不再弹** |
| 系统设了「减少动态效果」的设备 | 只淡入淡出,不滑动 |

## 🧠 什么时候弹、什么时候不弹

**同时有几个弹窗上线时,只弹一个**:按优先级(数字大的先),一样就看开始时间晚的;如果它在当前页面被排除了,就轮到下一个。

**不弹的页面**(服务器判断,被排除的页面连代码都不输出):
- ✅ 默认自动排除:**按钮链接指向的那一页**(比如按钮去 /collections/bfcm,黑五活动页本身就不弹)
- ✅ 默认排除:购物车页、会员账号页、404 页
- 可选:按页面类型排除(首页 / 产品页 / Collection 页 / 搜索页 / 博客 / 普通页面)
- 可选:按链接排除(填几个链接,以它开头的都不弹,比如 `/collections/bfcm`、`/pages/black-friday`)

**频率(存在客人浏览器里,不收集任何个人信息)**:
- 任何弹窗弹过后,**全站 1 小时内不再弹任何弹窗**(避免两个活动轮流打扰)
- 同一个弹窗**一天最多 3 次**
- 点了 × 的弹窗**当天不再弹**(第二天重新算)
- 「一天」按客人自己手机 / 电脑的日期

**这些情况先等一等,不立刻弹**:
- 页面在后台(客人切去别的标签页):等回来再开始
- 购物车抽屉、搜索弹窗、手机菜单正开着:等关了
- 客人正在输入框里打字:等打完
- **Cookie 提示还在**:电脑上卡片排在它上面;手机上等客人点完 Cookie 提示再弹(两条叠在手机底部太挤)
- 手机产品页有底部加购条:卡片放在加购条上面

**测试用**:链接后面加 `?cgp_popup=show` 强制弹出(不算次数,方便同事检查);`?cgp_popup=reset` 清掉这台设备的记录。

## 🛠 后台(网站更新中心)怎么用

左侧导航「网站内容」下新增 **「促销弹窗」**。列表页和其他内容一样(状态筛选 + 搜索 + 每行:小图 / 标题 / 时间 / 状态)。

编辑页按现有规范分段(「什么时候显示」永远最后):

1. **内容**:小图(上传图片 / 选择图片,和 Banner 一样)、标题、一句话、按钮文字、按钮链接
2. **倒计时**:开 / 关;文案(默认 `Ends in`);样式沿用活动倒计时的 4 种(经典 / 胶囊 / 黑金 / 只有文字);
   「最后 N 天才显示倒计时」(0 = 一直显示)。倒计时到**活动或弹窗自己的结束时间**,没有结束时间就不显示倒计时
3. **配色**:默认跟网站主题(按钮色作强调色);可选「黑金」(黑五)或自己填底色 / 文字色
4. **在哪些页面显示**:上面说的排除规则;下面一行人话总结,比如「全站都弹,除了:按钮去的 /collections/bfcm、购物车页」
5. **显示方式**:等几秒出现(默认 2)、停留几秒(默认 5)、隔几小时再弹(默认 1)、一天最多几次(默认 3)
6. **什么时候显示**:长期 / 设定时间 / 跟随活动(和 Banner 一样);优先级

右边**实时预览**:电脑页面缩略图里的左下卡片 + 手机框里的底部条,倒计时真的在走;「播放一遍」按钮看出现 → 停留 → 隐藏的动画。

活动页(活动总控台)里,跟随这个活动的弹窗会和 Banner、顶栏一起列在「挂在这个活动下的内容」里。

**统计效果**:按钮链接自动加上 `utm_source=cgp&utm_medium=popup&utm_campaign=<活动名>`(可关),
Shopify 后台「分析 → 报告 → 按 UTM 看会话 / 销售」就能看到弹窗带来多少人、多少单,不用另外装统计。

### B. 主题(共用的主题仓库)

| 文件 | 做什么 |
| --- | --- |
| `snippets/cgp-promo-popup.liquid`(新) | 读上线中的弹窗 → 按优先级挑第一个**这一页没被排除的** → 输出卡片(默认隐藏)+ 一小段设置;没有就什么都不输出 |
| `assets/cgp-promo-popup.js`(新,延迟加载,目标 < 5KB) | 频率记录、等待条件(Cookie / 抽屉 / 输入 / 后台标签页)、出现 / 停留 / 隐藏、倒计时、× 关闭、悬停暂停、测试参数 |
| 样式 | 直接写在 snippet 里(很少,省一次加载) |
| `layout/theme.liquid` | `</body>` 前加一行 `{% render 'cgp-promo-popup' %}` —— **只加这一行** |

速度:卡片是浮在页面上的,**不会挤动页面内容**;图片只在弹出时才加载、按 2 倍清晰度裁小图;页面加载完才开始计时,不影响首屏速度。
无障碍:不抢键盘焦点、能用 Esc 关、× 按钮有读屏名字、悬停 / 聚焦时不消失。
